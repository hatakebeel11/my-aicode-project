# GLOSSARY.md

This glossary defines core terminology used across the project codebase and architecture.

- **AiCode Workspace**: The root container workspace (`~/workspace`) where code, documentation, and agent configurations reside.
- **Custom Prompts**: User-defined system prompt fragments located in `~/.aicode/prompts.custom/` that override or extend default model instructions.
- **Issue Tracker**: Local markdown-based issue management system operating via `.scratch/` directories.
